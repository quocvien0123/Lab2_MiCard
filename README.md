## 1. Mục tiêu Lab
Xây dựng giao diện danh thiếp điện tử / trang profile cá nhân (MiCard) bằng các component cơ bản của React Native, làm quen với styling, bố cục flexbox, hiển thị avatar hình tròn, card thông tin liên lạc (Phone, Email) và icon đi kèm.

## 2. Công nghệ sử dụng
- **React Native** (v0.86.3)
- **TypeScript**
- **Expo SDK** (~57.0.25)
- **Expo Status Bar**
- Các component: `View`, `Text`, `Image`, `Pressable`, `StyleSheet`

## 3. Cách chạy project

### Cài đặt dependencies:
```bash
npm install
```

### Khởi chạy ứng dụng:
```bash
npx expo start
```

- Nhấn phím `a` trên terminal để mở trực tiếp trên **Android Emulator**.
- Hoặc quét mã QR qua ứng dụng **Expo Go** trên thiết bị thật.
